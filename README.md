# 🩸 Projeto Sangue Amigo

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![Java](https://img.shields.io/badge/Java-F7DF1E?logo=java&logoColor=white)

Protótipo em desenvolvimento de um **sistema voltado para a doação de sangue, plasma e plaquetas**, desenvolvido utilizando a linguagem **Java**.  
O objetivo do projeto é criar uma ferramenta digital para auxiliar na **gestão de doações** e incentivar a prática da doação de sangue.

---

## 🧩 Sobre o projeto

O **Projeto Sangue Amigo** visa:
- Gerenciar informações de doadores e tipos de doações;  
- Controlar agendamentos e histórico de doações;  
- Fornecer um protótipo funcional para estudo de **Java e POO**;  
- Praticar boas práticas de desenvolvimento e organização de sistemas.

---

## 🚧 Status do projeto

> 🟡 **Em desenvolvimento**  
> Novas funcionalidades e melhorias serão implementadas ao longo do progresso do projeto.

---

## ⚙️ Tecnologias utilizadas

- **Java** ☕  
- Programação Orientada a Objetos (POO) 🧩  
- Git e GitHub 🧰  

---

## 🎯 Objetivos de aprendizagem

- Aplicar conceitos de **POO** em um projeto real;  
- Desenvolver lógica de programação em **Java**;  
- Construir um sistema funcional para **gerenciamento de doações**;  
- Praticar versionamento e organização de código.
